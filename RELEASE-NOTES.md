# Podcast Brain 4.0 Release Notes

Podcast Brain 4.0 turns the existing recording tools into a focused Studio product.

Core promise:

> OBS records. Premiere edits. Podcast Brain remembers.

The Studio now prioritizes the real weekly workflow for A Little Throuple Tea:

1. Prepare the episode.
2. Run the recording.
3. Capture useful timestamps.
4. Complete Wrap while the conversation is fresh.
5. Generate one production packet for the Dashboard.

This build intentionally does not add direct OBS control yet. OBS connection testing comes after 4.0 is confirmed live so connection troubleshooting cannot destabilize the recording workflow.
